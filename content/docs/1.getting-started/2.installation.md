# Installation

Get up and running with Rakta.js in seconds using your preferred package manager. We recommend Bun for the best experience.
Requirements

Before installing Rakta.js, ensure your development environment meets the following requirements:

    •Node.js 18.17.0 or newer, OR Bun 1.0.0 or newer.
    • A package manager:
    bun
    npm
    yarn
    pnpm
    •Git for version control (optional but recommended).

While Rakta.js works perfectly with Node.js, we strongly recommend using Bun. Rakta.js's internal build engine (CheribonEngine) is heavily optimized for Bun's runtime, providing significantly faster installation, transpilation, and development server startup times.
Create Your First App

The easiest way to start a new Rakta.js project is by using the official CLI tool. Run the following command in your terminal: 

```bash
bun create-rakta-app@latest my-app
```
