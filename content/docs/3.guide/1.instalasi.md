# Instalasi Modul

Jika kamu ingin menambahkan Nuxt Content ke project Nuxt 4 yang sudah berjalan:

```bash
npx nuxi module add content
```

Perintah ini akan otomatis:

1. Menambahkan `@nuxt/content` ke `dependencies`
2. Mendaftarkan module di `nuxt.config.ts`

Jika ingin melakukannya manual, install package-nya lebih dulu:

```bash
npm install @nuxt/content
```

Lalu daftarkan di konfigurasi:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@nuxt/content']
})
```

Terakhir, buat file `content.config.ts` di root project untuk mendefinisikan collection:

```ts [content.config.ts]
import { defineContentConfig, defineCollection, z } from '@nuxt/content'

export default defineContentConfig({
  collections: {
    docs: defineCollection({
      type: 'page',
      source: '**/*.md'
    })
  }
})
```
