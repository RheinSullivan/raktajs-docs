# Syntax Highlighting

Nuxt Content menggunakan [Shiki](https://shiki.style) untuk menyorot (highlight) blok kode
secara otomatis berdasarkan bahasa yang ditulis setelah tiga backtick.

## Konfigurasi tema

Tema diatur di `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  content: {
    build: {
      markdown: {
        highlight: {
          theme: {
            default: 'github-light',
            dark: 'github-dark'
          },
          langs: ['bash', 'python', 'go', 'rust']
        }
      }
    }
  }
})
```

## Contoh JavaScript / TypeScript

```ts
interface User {
  id: number
  name: string
}

function greet(user: User): string {
  return `Halo, ${user.name}!`
}
```

## Contoh Vue

```vue
<script setup lang="ts">
const count = ref(0)
</script>

<template>
  <button @click="count++">Klik: {{ count }}</button>
</template>
```

## Contoh Python

```python
def fibonacci(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## Contoh Go

```go
package main

import "fmt"

func main() {
	fmt.Println("Halo dari Go!")
}
```

## Contoh Bash

```bash
for f in *.md; do
  echo "Memproses $f"
done
```

## Highlight baris tertentu & judul file

Kamu bisa menambahkan nama file dan menyorot baris tertentu:

```ts [utils/sum.ts] {2}
function sum(a: number, b: number) {
  return a + b // baris ini disorot
}
```
